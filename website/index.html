Häufige Fragen

Kurz und ehrlich.

Windows warnt beim Start des Installers

Neue Programme ohne teures Code-Signing-Zertifikat zeigt Windows SmartScreen erst als „unbekannt“ an. Klick auf „Weitere Informationen“ → „Trotzdem ausführen“. Der Installer wird automatisch aus dem öffentlichen Quellcode gebaut.

Ist mein Konto sicher?

Ja. Die Anmeldung läuft über den offiziellen Microsoft-Login im Browser. ShadowClient sieht dein Passwort nie, das Anmelde-Token liegt verschlüsselt in der Windows-Anmeldeinformationsverwaltung.

Ist das erlaubt auf Servern?

ShadowClient enthält keine Cheats – nur Anzeige- und Komfort-Module, wie sie auch andere bekannte Clients haben. Halte dich trotzdem an die Regeln des jeweiligen Servers.

Welche Minecraft-Versionen?

Die ShadowClient-Mod gibt es für 1.21.11. Profile für andere 1.21-Versionen startest du mit Fabric, aber ohne ShadowClient-Menü.

Kostet das etwas?

Nein. ShadowClient ist kostenlos. Du brauchst nur ein eigenes Minecraft: Java Edition.
